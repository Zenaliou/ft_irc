- Operators:
	classe Client avec plus de droits. kick = fermer la co Client <-> Server(Channel).

- Channel:
	1 Client minimum. Creation quand un Client JOIN, destruction quand le dernier Client quitte.
	Client peut faire reference a un channel existant.
	_name commence par '&' ou '#', length de 200 char. Pas de :
		- Space | ' '
		- Bell | ctrl+G | 7
		- Comma | ',' (utilise en separateur pour IRC protocol)
	'&' local et '#' global --> pour ft_irc, c'est pareil (Pas de multi server)

- JOIN:
	Rejoindre ou Creer un channel
	Creer -> user devient un Operator
	Rejoindre:
		- MODE i (inviteOnly) -> JOIN si invite
		- Limite a 10 Channel/Client (RFC 8.13)

- Channel Operators:
	'@' + nickname (NAMES, WHO, WHOIS commands)
	KICK
	MODE
	INVITE
	TOPIC

- lowercase("[]\") == "{}|"

- Messages:
	Commande valide -> reponse attendue
	IRC message -> 3 parties max: prefix(optionnal), command, params (15max)
	Separation par 1 ou plusieurs space ' '
	Prefix:
		Commence par ':', qui doit etre le premier char du message. Pas de whitespace apres ':'
		Indique l'origine du message
	Les messages se terminent par CR-LF ("\r\n"). 512 length max (CRLF inclut)

	<message>  ::= [':' <prefix> <SPACE> ] <command> <params> <crlf>
	<prefix>   ::= <servername> | <nick> [ '!' <user> ] [ '@' <host> ]
	<command>  ::= <letter> { <letter> } | <number> <number> <number>
	<SPACE>    ::= ' ' { ' ' }
	<params>   ::= <SPACE> [ ':' <trailing> | <middle> <params> ]

	<middle>   ::= <Any *non-empty* sequence of octets not including SPACE
               or NUL or CR or LF, the first of which may not be ':'>
	<trailing> ::= <Any, possibly *empty*, sequence of octets not including
                 NUL or CR or LF>
	<crlf>     ::= CR LF

	<target>     ::= <to> [ "," <target> ]
	<to>         ::= <channel> | <user> '@' <servername> | <nick> | <mask>
	<channel>    ::= ('#' | '&') <chstring>
	<servername> ::= <host>
	<host>       ::= see RFC 952 [DNS:4] for details on allowed hostnames
	<nick>       ::= <letter> { <letter> | <number> | <special> }
	<mask>       ::= ('#' | '$') <chstring>
	<chstring>   ::= <any 8bit code except SPACE, BELL, NUL, CR, LF and
                     comma (',')>

	Other parameter syntaxes are:
	<user>       ::= <nonwhite> { <nonwhite> }
	<letter>     ::= 'a' ... 'z' | 'A' ... 'Z'
	<number>     ::= '0' ... '9'
	<special>    ::= '-' | '[' | ']' | '\' | '`' | '^' | '{' | '}'
	<nonwhite>   ::= <any 8bit code except SPACE (0x20), NUL (0x0), CR
                     (0xd), and LF (0xa)>
